fs-cortex

Tu IA recuerda.
Automaticamente.

Un sistema de aprendizaje continuo para Claude Code. Observa como trabajas, detecta patrones y los cristaliza en conocimiento reutilizable — sin que tengas que hacer nada.

El problema

Claude empieza de cero cada sesion

Imagina un empleado brillante que cada manana olvida TODO lo que aprendio ayer. Le explicas que en tu proyecto siempre se usan conventional commits, que nunca se hardcodean secretos, que el componente de autenticacion tiene un bug especifico... y manana te lo vuelve a preguntar.

Eso es Claude Code sin Cortex. Cada sesion es una pizarra en blanco. Tus preferencias, los errores que ya resolviste, los patrones de tu proyecto — todo se pierde.

El coste de repetir

Cada vez que re-explicas algo a Claude, pierdes tiempo y tokens. Cada error que ya resolviste pero se vuelve a cometer es frustracion acumulada. Los mejores equipos documentan su conocimiento — tu IA deberia hacer lo mismo.

Como lo resuelve Cortex

Cortex observa cada sesion de trabajo y convierte los patrones que detecta en conocimiento persistente. Todo sucede con 4 pasos:

1 Observar Graba cada accion
→
2 Analizar Detecta patrones
→
3 Validar Tu confirmas
→
4 Inyectar Claude recuerda

Paso 1: Observar (automatico)

Cada vez que usas una herramienta en Claude Code (editar un archivo, ejecutar un comando, buscar codigo), Cortex lo anota silenciosamente. No consume tokens, no ralentiza nada. Solo observa.

Paso 2: Analizar (tu lo ejecutas)

Cuando Cortex ha observado suficientes acciones (~50), te sugiere ejecutar /cx-analyze. Este comando revisa tus observaciones y propone "instintos" — reglas que ha detectado en tu forma de trabajar.

Ejemplo: "Cuando editas un archivo de API, siempre ejecutas los tests despues" → Cortex propone un instinto que lo recuerde.

Paso 3: Validar (tu decides)

Cortex nunca aprende sin tu permiso. Con /cx-validate revisas cada propuesta: aceptar, rechazar o saltar. Solo lo que tu confirmas se convierte en conocimiento activo.

Paso 4: Inyectar (automatico)

A partir de ese momento, cada vez que uses una herramienta que coincida con el patron, Cortex le recuerda a Claude la regla. Sin que tu hagas nada. Sin repetirte.

Y mas alla: Los instintos que usas mucho se destilan en leyes universales (/cx-distill). Los clusters de instintos maduros se evolucionan en skills, comandos, reglas y agentes reutilizables (/cx-evolve). Y un sistema de limpieza automatica (/cx-dream) elimina duplicados y contradicciones.

Antes y despues

Sin Cortex

  • Claude olvida tus preferencias cada sesion
  • Repites las mismas instrucciones una y otra vez
  • Los mismos errores se cometen multiples veces
  • No hay historial de lo que funciono y lo que no
  • Cada proyecto empieza de cero

Con Cortex

  • Claude recuerda tus reglas y preferencias siempre
  • Los patrones se detectan y aplican automaticamente
  • Los errores resueltos se capturan como "gotchas"
  • El conocimiento crece con cada sesion de trabajo
  • Los patrones de un proyecto se promueven a otros

Como evoluciona el conocimiento

Cada pieza de conocimiento tiene una puntuacion de confianza que crece con el uso y decae con el tiempo. Lo que usas mucho se fortalece. Lo que no usas se desvanece.

0.2

Borrador

Patron detectado pero aun no inyectado. Cortex lo observa en silencio.

0.4

Hipotesis

Tu lo validaste. Se inyecta cuando el trigger coincide con la herramienta.

0.6

Patron

Se ha activado varias veces. Claude lo aplica con regularidad.

0.8

Instinto

Conocimiento consolidado. Candidato a promocion como ley universal.

0.9

Ley

Conocimiento cristalizado. Se inyecta en CADA sesion, siempre presente.

Decay natural: Si no usas un patron durante 30 dias, su confianza baja -0.05. Despues de 90 dias sin uso, se archiva automaticamente. Ademas, los instintos con 60+ dias sin uso se saltan silenciosamente en la inyeccion, sin esperar al ciclo de limpieza. Tu conocimiento activo siempre esta fresco y relevante.

Empezar en 3 pasos

1. Clonar

git clone https://github.com/fermonterom/fs-cortex.git
cd fs-cortex

2. Instalar

bash install.sh

El instalador configura todo: hooks, comandos, permisos y datos iniciales. Tus datos existentes se preservan en actualizaciones.

3. Trabajar

Abre Claude Code y trabaja normal. Cortex aprende solo. Cuando veas un recordatorio, ejecuta el comando que te sugiere. Nada mas.

Requisitos: Python 3, Node.js, Claude Code instalado. Compatible con macOS, Linux y Windows (PowerShell).
