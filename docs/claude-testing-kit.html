Claude Testing Kit

Un kit portable que convierte a Claude Code en un agente de testing estricto. Copia la carpeta .claude/ a cualquier proyecto Next.js y obtendras TDD automatico, E2E obligatorio, y cero codigo sin tests.

01

Que es esto

Concepto

No es un framework de testing — usa Vitest y Playwright existentes. No es una app — no tiene package.json ni codigo de produccion. Es un kit de configuracion para Claude Code: reglas, skills, comandos y hooks que ensenan a Claude a testear tu proyecto Next.js de forma sistematica siguiendo TDD estricto.

02

El problema que resuelve

Claude sin el kit

Lo que pasa por defecto

  • Genera codigo sin tests
  • Commits sin cobertura
  • Tests escritos despues (o nunca)
  • Sin estandar de cuantos tests
  • Bugs en produccion

Claude con el kit

Testing automatico y obligatorio

  • TDD obligatorio en API routes
  • E2E obligatorio antes del commit
  • Minimo 6 tests por endpoint
  • Pre-commit hooks bloquean
  • /check-tests genera lo que falta
Regla de oro: Nunca commitear un route.ts sin route.test.ts. Nunca commitear un page.tsx sin su .spec.ts.

TDD: Test First, Code Second

El tipo de archivo determina CUANDO se escribe el test. route.ts = test ANTES. page.tsx = test DESPUES, antes del commit.

Siempre vertical: un test → su codigo → green → siguiente. Nunca horizontal (todos los tests primero, luego todo el codigo).

Unit tests (Paso 6)

Lee cada route.ts sin test. Identifica metodos HTTP, validaciones, tablas. Crea route.test.ts con 6+ casos. Ejecuta y corrige hasta que pase.

E2E tests (Paso 7)

Solo empieza cuando todos los unit tests pasan. Verifica que el dev server este corriendo. Lee cada page.tsx, crea .spec.ts en tests/.

Convencion de nombres: src/app/(dashboard)/settings/profile/page.tsx → tests/settings-profile.spec.ts. Se quitan route groups, se reemplaza / con -.

Git Hooks: gates automaticos

Husky pone guardianes automaticos en Git. Si algo falla, el codigo no se sube.

pre-push

curl :3000
→

→
Push OK
Pre-commit bloquea. Pre-push solo ejecuta E2E si el dev server esta arriba — si no, avisa pero no bloquea.

09

Instalacion (una sola linea)

Abre Claude Code dentro de tu proyecto Next.js y pega esto:

Pega en Claude Code
Instala el testing kit desde https://github.com/fermonterom/claude-testing-kit

Eso es todo. Claude clona el repo, lee las instrucciones, y configura todo automaticamente: detecta tu package manager, estructura del proyecto, instala dependencias, crea configs y hooks.

Lo que Claude hace por ti
  • + Detecta npm/pnpm/yarn/bun
  • + Copia .claude/ (merge si ya existe)
  • + Instala Vitest + Playwright + Husky
  • + Crea vitest.config.ts + playwright.config.ts
  • + Configura git hooks (pre-commit + pre-push)
Requisitos
  • — Claude Code
  • — Node.js 18+
  • — Next.js 14+ (App Router)
  • — TypeScript
  • — Estructura src/app/ o app/
Tu no programas tests. Defines las reglas. Claude hace el trabajo.
